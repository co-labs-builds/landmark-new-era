How these were counted

“Empty” means null, empty string, 0, or 0.00 — the values Ontraport stores for an unset check, dropdown, parent or price field. Every count below is a full census of the record set named, not a sample.

Two field types could not be read this way. related_data mirrors (f3099–f3102, f2394, f3080, the portal visibility mirrors) and subscription fields are silently dropped from list queries. They are computed from the parent record, so “unused” does not apply to them the same way.

Automations are measured by records currently attached. Ontraport can detach a record when it completes an automation, so zero attached is strong evidence of never having fired — not absolute proof. Treat the [LIVE]-named entries with zero as things to confirm in the UI before deleting.

WORTH KNOWINGTwo things that change how you read the earlier map

  1. Graduation attendance is being captured. f2666 on the contact holds 214 records. The Forum Cycle map treats this as missing because it reads f3361, which is empty. Fix the pointer, not the pipeline.
  2. The f2674 override check covers less than you would want. The map proposes comparing registration f2674 Email against the contact’s email to detect cookie overrides. f2674 is populated on only 22 of 133 event-218 registrations, so that check can see about one registration in six. It is still worth shipping — it caught the 20 Aug incident — but it needs f2674 written on every registration to be a real safety net.
What this audit did not cover

Contacts: roughly 110 fields were censused. Free-text NPS responses (f2604, f2605, f2608–f2614, f2618, f2619) were checked as a group — 4 of 667 contacts have any of them set. Social links and address2 were checked as a group — 52 of 667. Attribution fields (n_campaign, l_lead_source and siblings) were not checked.

Not measurable through the API: related_data mirror fields, subscription fields as list output, invoice-scoped automation membership, and object types 217 and 230.

Nothing was written. Every call in this audit was a read.
