Only state changes are recorded — crossing into watch or at-limit, returning to healthy, HTTP 429s, and probe failures.

    How to read this. Ontraport applies one rolling per-minute limit to the whole account, and reports it on every response via X-Rate-Limit-Limit, X-Rate-Limit-Remaining and X-Rate-Limit-Reset. This page calls /webhook/ontraport-rate-probe, which makes exactly one lightweight Ontraport request and returns those three headers. Each poll therefore costs 1 request against the same budget, and the “used” figure includes this page’s own probes — the tile above states how much of the limit this tab is consuming. A 429 means a request was rejected outright; whichever integration made it will have failed, not queued.
